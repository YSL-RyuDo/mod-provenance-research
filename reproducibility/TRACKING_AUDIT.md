# Git Preservation and Tracking Audit

Audit date: 2026-08-18 (Asia/Seoul)

## Baseline

- Existing preserved commit: `7003afeb87ae6ad0e0282386804fe9031c22e674`
- Existing branch: `main`
- Existing local remote-tracking ref: `origin/main`
- Baseline relationship: local `HEAD` and the recorded `origin/main` ref were identical.
- The baseline commit already contained Phase 1-11 scripts and summary artifacts. The gap was not missing early-phase history; it was missing detailed tables, servers/tools, paper assets, and an explicit index.

The exact pre-change untracked inventory is recorded in `UNTRACKED_CLASSIFICATION.csv`. Every untracked path reported by `git ls-files --others --exclude-standard` at the baseline was assigned one of the classifications below.

## Included in the preservation commit

`TRACK_REPRODUCIBILITY` covers:

- all public analysis code and Phase 9 server implementations;
- the Java bytecode helper source (`tools/phase3d/JavapBatch.java`), but not its compiled class;
- Phase 1-11 detailed result CSVs, frozen splits, public/evaluation-private manifests, scores, predictions, audits, and summaries;
- environment freezes and the experiment index;
- the LaTeX manuscript source, compiled draft PDF, figure-generation helper, and paper figures;
- archived copies of the deterministic Phase 11 generated adapter and the Phase 10 NiCad scorer version whose ground-truth/K logic was invalid.

Evaluation-private CSVs contain frozen source labels or anonymous-to-internal mappings needed to reproduce results. They do not contain credentials or raw component bytes. Their presence is why the repository must remain private until a separate public-release sanitization step is performed.

## Excluded but preserved locally

| Classification | Paths / rule | Reason |
|---|---|---|
| `EXCLUDE_RAW_DATA` | `data/`, `*.jar`, `*.zip`, archives | Third-party/raw payloads and generated packages can be large or unsuitable for redistribution. |
| `EXCLUDE_CACHE` | `cache/` | 920 baseline untracked files were downloaded/cloned repository cache internals and can be reconstructed from tracked mappings and refs. |
| `EXCLUDE_ENV` | `.venv/`, `venv/`, `env/` | Machine-specific virtual environment; exact package records are tracked instead. |
| `EXCLUDE_BUILD` | `__pycache__/`, `*.pyc`, `*.class`, `*.aux`, `*.log`, `*.synctex.gz` | Generated interpreter/compiler/manuscript output. |
| `EXCLUDE_TRANSIENT_RESULT` | stdout, timing, bootstrap-replicate CSVs, NiCad stderr/time files | Large/noisy rerun artifacts; summaries and point/interval results are tracked. |
| `EXCLUDE_GENERATED_ACTIVE` | `scripts/_phase11b_phase7h_adapter_generated.py` after regeneration | Deterministically produced by the tracked Phase 11B driver; the audited historical copy is in `archive/generated/`. |
| `EXCLUDE_LOCAL_DEBRIS` | root `0`, `Foo`, and `earch state through Phase11A*` | Empty placeholders and an accidental redirected `git diff --stat` output. Left untouched on disk and explicitly ignored. |

## Archive decisions

- `archive/generated/_phase11b_phase7h_adapter_generated.py` is retained as an audit snapshot. The active script is generated by `phase11b_run_multi_unknown_robustness.py`, so it is not a hand-maintained source of truth.
- `archive/failed_experiments/phase10a4d_score_nicad_v1_buggy.py` is retained to document a superseded baseline result. It incorrectly used internal `source_fresh_id` as evaluation truth for held-out queries and omitted the collapsed `UNKNOWN` contribution to predicted K. The corrected active implementation is `scripts/phase10a4d_score_nicad.py`.

No original research artifact was deleted. Files excluded from Git remain on the local filesystem; archived files are renames/copies retained in version history.

## Public-release warning

This preservation commit is designed for a private research repository. Before any public release, create a separate sanitized export that removes evaluation-private mappings, reviews third-party metadata/licensing, and confirms that no historical commit exposes material intended to remain private.

`TRACK_REPRODUCIBILITY`에 포함되는 항목은 다음과 같습니다.

## Git에서 제외하지만 local에 보존한 항목

| Classification | 경로 / rule | 이유 |
|---|---|---|
| `EXCLUDE_RAW_DATA` | `data/`, `*.jar`, `*.zip`, archive | 제3자/raw payload와 생성 package는 크거나 재배포에 부적합할 수 있습니다. |
| `EXCLUDE_CACHE` | `cache/` | 기준 untracked 파일 920개는 download/clone한 저장소 cache 내부 자료이며 추적되는 mapping과 ref로 복원할 수 있습니다. |
| `EXCLUDE_ENV` | `.venv/`, `venv/`, `env/` | Machine별 가상환경이며 대신 정확한 package 기록을 추적합니다. |

## Archive 결정

- `archive/generated/_phase11b_phase7h_adapter_generated.py`는 audit snapshot으로 보존합니다. 활성 script는 `phase11b_run_multi_unknown_robustness.py`가 생성하므로 사람이 유지하는 source of truth가 아닙니다.
- `archive/failed_experiments/phase10a4d_score_nicad_v1_buggy.py`는 대체된 baseline 결과를 기록하기 위해 보존합니다. Held-out query에서 internal `source_fresh_id`를 evaluation truth로 잘못 사용했고 predicted K에서 collapsed `UNKNOWN` 기여를 빠뜨렸습니다. 수정된 활성 구현은 `scripts/phase10a4d_score_nicad.py`입니다.

원본 연구 artifact는 삭제하지 않았습니다. Git에서 제외한 파일은 local filesystem에 그대로 있으며 archive 파일은 version history에 보존된 rename/copy입니다.

## 공개 release 경고

이 보존 commit은 private 연구 저장소를 위해 설계되었습니다. 공개하기 전에는 evaluation-private mapping을 제거하고, 제3자 metadata/license를 검토하며, private으로 유지할 자료가 과거 commit에 노출되지 않는지 확인한 별도의 sanitized export를 만드세요.

## Gitから除外しlocalに保存する項目

| Classification | Path / rule | 理由 |
|---|---|---|
| `EXCLUDE_RAW_DATA` | `data/`、`*.jar`、`*.zip`、archive | 第三者/raw payloadと生成packageは大容量または再配布に不適切な場合があります。 |
| `EXCLUDE_CACHE` | `cache/` | 基準untrackedファイル920件はdownload/cloneしたリポジトリcache内部資料であり、追跡済みmappingとrefから復元できます。 |
| `EXCLUDE_ENV` | `.venv/`、`venv/`、`env/` | Machine固有の仮想環境であり、代わりに正確なpackage記録を追跡します。 |
| `EXCLUDE_BUILD` | `__pycache__/`、`*.pyc`、`*.class`、`*.aux`、`*.log`、`*.synctex.gz` | 生成されたinterpreter/compiler/manuscript outputです。 |
| `EXCLUDE_TRANSIENT_RESULT` | stdout、timing、bootstrap-replicate CSV、NiCad stderr/timeファイル | 大容量でnoiseの多いrerun artifactです。summaryとpoint/interval resultは追跡します。 |
| `EXCLUDE_GENERATED_ACTIVE` | 再生成後の`scripts/_phase11b_phase7h_adapter_generated.py` | 追跡済みPhase 11B driverが決定論的に生成します。監査済みの過去copyは`archive/generated/`にあります。 |
| `EXCLUDE_LOCAL_DEBRIS` | ルートの`0`、`Foo`、`earch state through Phase11A*` | 空placeholderと、誤ってredirectされた`git diff --stat` outputです。Disk上の原本には触れず明示的に無視しました。 |

## Archive判断

- `archive/generated/_phase11b_phase7h_adapter_generated.py`はaudit snapshotとして保存します。active scriptは`phase11b_run_multi_unknown_robustness.py`が生成するため、人が保守するsource of truthではありません。
- `archive/failed_experiments/phase10a4d_score_nicad_v1_buggy.py`は、置き換えられたbaseline結果を記録するために保存します。Held-out queryでinternal `source_fresh_id`をevaluation truthとして誤用し、predicted Kからcollapsed `UNKNOWN`の寄与を除外していました。修正済みactive実装は`scripts/phase10a4d_score_nicad.py`です。

元の研究artifactは削除していません。Gitから除外したファイルはlocal filesystemに残り、archiveファイルはversion historyに保存されたrename/copyです。

## 公開release警告

この保存commitはprivate研究リポジトリ向けです。公開前に、evaluation-private mappingを削除し、第三者metadata/licenseを確認し、privateに保つべき資料が過去commitに露出していないことを確認した別のsanitized exportを作成してください。
